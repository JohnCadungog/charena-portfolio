# Charena Mendoza — Portfolio

Personal portfolio for Charena Mae S. Mendoza, virtual assistant, chat support professional, and ESL teacher based in Cebu City, Philippines. Designed as a business letter: letterhead, opening, enclosures, signed close.

Built with Vite and vanilla JS/CSS. Deployed on Vercel.

```bash
npm install
npm run dev
```

To add a photo, drop it in `public/` and replace the `.mounted__mono` span in `index.html` with `<img src="/your-photo.jpg" alt="Portrait of Charena Mendoza">`.
