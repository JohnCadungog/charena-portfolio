# Charena Mendoza — Portfolio

Personal portfolio for Charena Mae S. Mendoza, virtual assistant, chat support professional, and ESL teacher based in Cebu City, Philippines.

Built with Vite and vanilla JS/CSS. Deployed on Vercel.

```bash
npm install
npm run dev
```

To add a photo, drop it in `public/` and replace the contents of `.idphoto__frame` in `index.html` with an `<img>`.
